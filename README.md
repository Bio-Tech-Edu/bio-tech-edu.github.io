# Vitrine Bio‑Tech‑Edu

Site estático que reúne os Objetos de Aprendizagem Digital (OAD), Recursos Educacionais Abertos (REA) e Recursos Educacionais Digitais (RED) públicos desenvolvidos pela marca Bio‑Tech‑Edu.

Este repositório publica o site em https://bio-tech-edu.github.io/

## Estrutura

- `index.html` — página única (hero, tipos de recurso, catálogo com busca e filtros, metodologia, sobre).
- `assets/styles.css` — tema escuro verde/aqua, com foco visível, `prefers-reduced-motion` e textos a partir de 12 px.
- `assets/script.js` — lista `projects` e renderização do catálogo. Para cada recurso, o campo opcional `alt` define o texto alternativo da captura.
- `assets/screenshots/` — capturas reais dos recursos.

Versão inicial gerada via Copilot; revisada e redesenhada na v2 (wireframes + correções de acessibilidade).
